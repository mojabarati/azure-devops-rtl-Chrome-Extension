# Chrome Web Store Promotional Asset Plan

Prepare promotional artwork without fabricating product screenshots or implying Microsoft endorsement.

## Small promotional tile

- **440×280 pixels**
- PNG or JPEG
- Required for the Store listing under current Chrome Web Store guidance

Use the extension's own name/logo, a simple RTL-text motif, and restrained copy. Keep important elements away from edges and verify legibility at reduced size.

## Marquee promotional image

- **1400×560 pixels**
- PNG or JPEG
- Optional; used if the item is selected for marquee placement

## Branding cautions

- Do not use Microsoft logos, badges, or wording that implies an official relationship.
- Include only artwork the publisher has the right to use.
- The current extension logo resembles Azure branding and its 128px artwork sits close to some canvas edges; obtain trademark and Store-presentation decisions before submission rather than silently changing it here.
- Promotional images are not substitutes for real Store screenshots.

Official references:

- <https://developer.chrome.com/docs/webstore/images>
- <https://developer.chrome.com/docs/webstore/best-listing>
